Простая программа для отслеживания своих финансов.

Для работы необходимо создать папку с годом в формате: 2020_год или 2020_year в папке с проектом.
В этой папке создать txt файлы для каждого месяца в формате: сентябрь.txt или september.txt.

После запуска выбираете папку, добавляете/удаляете заметки и следите за деньгами!
