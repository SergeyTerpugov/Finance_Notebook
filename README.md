💰 Финансовый Блокнот
Простое десктопное приложение для учёта личных финансов по месяцам. Ведёте записи в текстовых файлах, а программа считает прибыль, траты и общий баланс.

Возможности
📂 Выбор файла месяца через диалог — год берётся из названия папки, месяц — из имени файла.

➕ Добавление записей в формате Цена:Описание (например, -500:Продукты, 30000:Зарплата).

🗑️ Удаление записи по ID.

📊 Отчёт: прибыль, траты и итоговый баланс за месяц.

💾 Чтение и запись .txt в кодировке UTF-8.

🛡️ Некорректные строки в файле пропускаются с сообщением в консоль — приложение не падает.
